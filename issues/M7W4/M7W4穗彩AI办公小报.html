个人 AI 使用榜

个人排名：排名按各工具使用量排序，分别统计本周个人在 Cursor、ChatGPT、Codex、Kiro 的使用指标。

其中，Cursor 榜单优先按 token 总数排序，数值相同再按交互次数；Codex 榜单优先按 token 总数排序，数值相同再按代码行数；Kiro 榜单优先按积分用量排序，如数值相同，则按交互次数补充排序；ChatGPT 榜单按交互次数排序。

token总数 = 本周个人在该工具中的输入、输出及缓存 token 总量；

代码行数 = Codex 本周排行榜里的代码行数；交互次数 = 本周个人向该工具发送的消息总数。

积分用量 = Kiro 会将模型消耗按平台规则换算成积分，榜单按该积分口径统计。

小招开箱记

一个小技巧，帮下周的自己少绕一点路。

⌘
Cursor 官方索引排查

用 View included files 确认它到底看到了什么

如果你怀疑 Cursor 没读到关键目录，或者反而把不该读的文件也带进来了，
可以直接查看 included files。这样能快速确认哪些路径真的进了索引，
也能顺手排查 `.gitignore` 或 `.cursorignore` 有没有把关键内容挡掉。

一句话用法：
到 Cursor Settings 的 Indexing & Docs 里
打开 View included files，先确认关键目录有没有被索引。
https://cursor.com/docs/chat/codebase-answers
<>
ChatGPT 官方个性化设置

用自定义指令，把常用要求一次说清

如果你总要重复交代“默认用中文、语气正式一点、适合工作群、别写太长”这类偏好，
可以把这些要求提前写进自定义指令里，让 ChatGPT 后面默认按这个口径来，省掉每次重说一遍。

一句话用法：
在“设置 > 个性化 > 自定义指令”里写好你的常用偏好，
后面直接开始提问。

8096356-custom-instructions-for-chatgpt
