# Office AI Weekly 首页与 GitHub Pages 设计

## 目标

为 `office-ai-weekly` 增加一个可直接访问的首页，并尝试通过 GitHub Pages 免费发布，用于查看最新一期办公 AI 小报。

## 页面设计

- 在仓库根目录增加 `index.html`。
- 首页显示“办公 AI 小报”标题、简短说明和最新一期 `M8W1`。
- 提供“查看最新一期”按钮，链接到 `issues/M8W1/M8W1穗彩AI办公小报.html`。
- 页面保持简洁，后续可以继续增加往期入口。

## 发布方式

- 使用 GitHub Actions 只把根目录的 `index.html` 和 `issues` 目录打包为 Pages 网站，不发布 README、设计说明等其他仓库文件。
- 仓库继续保持私有，但测试页面允许公开访问。
- 发布前检查打包内容，确认其中只包含首页、小报和小报使用的图片。
- 如果当前账户方案不支持从私有仓库发布 Pages，立即停止发布并报告 GitHub 返回的具体限制；不修改仓库可见性、付费方案或其他 Pages 设置。

## 修改范围

- 只增加首页和 Pages 发布所必需的配置。
- 不修改已经归档的 M8W1 HTML 与图片，不增加自定义域名、付费服务或无关网页功能。

## 验证

- 确认发布产物中只包含 `index.html` 和 `issues` 下的文件。
- 确认托管首页返回 HTTP 200。
- 确认首页按钮使用仓库 Pages 基础路径，并且打开最新一期时返回 HTTP 200。
- 确认小报中每个非 `data:` 的本地图片网址均返回 HTTP 200，浏览器中没有破损图片。
